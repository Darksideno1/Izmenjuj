# Faza 1 – računi in zbirke

V tej fazi so implementirani:

- registracija, prijava in odjava uporabnika,
- profil z lokacijo in načini menjave,
- javni katalog zbirk,
- dodajanje, urejanje in brisanje lastnih zbirk,
- osnovni podatki zbirke: naslov, podnaslov, opis, leto, proizvajalec/založnik, država in tip,
- naslovna slika zbirke,
- galerija dodatnih slik,
- osnutek ali javna objava,
- lokalna shramba slik za razvoj,
- Supabase Storage za gostovan test,
- PostgreSQL bootstrap ob prvem zagonu,
- Docker/Render konfiguracija za javni test.

## Še ni del Faze 1

Predmeti znotraj zbirke, variante, osebna evidenca Imam/Iščem/Za menjavo in samodejno iskanje menjav so naslednje faze.
